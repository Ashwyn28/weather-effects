# Security Policy

## Supported versions

Security fixes are applied to the latest release only.

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately through
[GitHub private vulnerability reporting](https://github.com/Ashwyn28/weather-effects/security/advisories/new)
on this repository.

Include what you found, the steps or a minimal page that reproduces it, and the affected version. You can expect an acknowledgement within a few days. Once a fix is released, the report will be disclosed with credit to you, unless you prefer otherwise.

weather-effects has no runtime dependencies and makes no network requests of its own; Three.js is supplied by the caller.
